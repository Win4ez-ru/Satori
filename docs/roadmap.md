# Roadmap

## Current scope

The current release concerns the desktop connected assistant. It extends the existing
source intake with a budgeted, read-only semantic route and repairs Telegram login
and view lifecycle. See [ADR-0115](decisions/0115-practical-connected-assistant.md)
and [release status](progress.md).

## Core

The Core implements typed persistent self, layered memory with provenance, affect,
relationship state, positions, reflection and bounded personality evolution. The
macOS engineering gate for whole-store retention and readiness is documented in
[ADR-0074](decisions/0074-whole-store-retention-and-readiness.md) and
[retention](retention.md). Character behavior work is paused. Stage 15
(autobiographical self) requires separate authorization.

## Open acceptance

- Live Gmail and Telegram answers from the ordinary release 26 composer.
- Portable Calendar and physical iPhone qualification.
- End-to-end calls and use while the Mac is asleep.
- Signed public macOS distribution and clean-machine verification.

The [long-term roadmap](roadmap-north-star.md) describes later work on perception,
permissions and actions.

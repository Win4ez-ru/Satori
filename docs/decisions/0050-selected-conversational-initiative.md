# ADR 0050: Selected conversational initiative

- Status: Superseded in part by [ADR-0051](0051-compact-owned-reaction-and-closure-bounds.md) for active V32 realization; historical V31 and all other boundaries remain accepted
- Date: 2026-09-28
- Supersedes: ADR-0049 only for active provider realization of an already selected ordinary
  conversational opening; its understated delivery and every earlier owner/boundary remain

## Context

The user preferred B (V30) to A (V29) in diagnostic 5, then requested occasional initiative:
a specific follow-up or proposed conversation topic, approximately 10–20% of ordinary replies.
Questions on every reply are unwanted. This relative preference does not accept the character.
The user explicitly authorized implementation after this feedback.

Both sampled versions selected the same single `advance_current` opportunity in six turns.
V30 realized it as advice to take a pause. This is a realization gap to investigate before
changing selection frequency. One selected opportunity in six is not an observed initiative rate.
The previously liked restrained closure remains positive evidence, not an emotion-state mutation.

## Decision

Introduce policy V31 as the implementation candidate. Keep V30 immutable and preserve the
selector, agency/presence/delivery/manifest schemas 1/3/5/17, cognition versions 2/3, all state
owners, grounding, generation parameters, output limits, validation and max-one retry path.

Within the existing single peer renderer, replace the general initiative sentence only when
`advance_current` is already selected, its subject is `current_exchange`, the delivery goal is
`celebrate_and_continue` or `owned_response`, and the affect profile is neither tense nor negative.
Clarify that one concrete conversational hook can become a specific detail question, connected
thought or new angle on the current topic. Unsolicited practical advice is not a substitute.
The provider need not ask a question, repeat known details or repeat a prior question. Current
corrections, listening requests and closure prevail; without a grounded hook, a complete reaction
is sufficient. Do not invent a hobby, memory or off-screen activity.

This does not select new moments, loosen `shift_adjacent` canonical-interest requirements,
change canonical position/interest contributions, impose a quota, append generated text or add
persistent conversational wishes. It does not alter explicit technical/creative task completion,
care or closure instructions. No new judge, rewrite, semantic retry or provider call is added.
The 10–20% preference is a longer-dialogue design target, not a turn counter or acceptance claim.

## Verification and gate

Freeze 58 pre-change V30 request/parameter hashes and preserve the matching source archive and
real local matrix. Reuse that verified matching-source V30 matrix as the before baseline. The
corpus covers neutral/tired/negative conditions, question corrections, explicit stop and ordinary
closure, relationship variants, explicit tasks, and available canonical interests. Compare all
typed decisions/cognition/parameters and every unaffected request byte except version metadata.
Test the actual default pipeline, exact commit/replay, unchanged self, fallback and shared retry.
Tests do not score the naturalness of provider output or require question marks.

Run Foundation checks and the real candidate matrix: three fresh exact-production dialogues,
30-turn coherence, independent activities, three relationship conditions, identity/independence
and the exact real CLI gender/identity scenario. Preserve every public reply and failure with
usage and timing evidence. Record selected opportunities separately from actual conversational
initiative; automatic punctuation counts and advice are not recognition evidence. Human semantic
scores remain unset. Local Qwen transport/character failures remain failures.

A later target-provider V30/V31 comparison must have a new frozen plan, separate explicit call/cost
authorization and a new one-shot claim. Earlier grants were consumed and are not reused. The six
public pairs can test this realization hypothesis, not establish a population frequency. A longer
ordinary-dialogue review remains necessary for the desired initiative distribution. Checkpoint
14.3 Phase A stays active; V10 remains accepted and later phases/stages stay closed.

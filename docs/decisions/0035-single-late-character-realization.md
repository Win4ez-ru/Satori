# ADR 0035: Single late character realization

- Status: Accepted
- Date: 2026-08-27
- Supersedes: ADR 0034 (provider rendering and advice realization only)
- Related: ADR 0021, ADR 0023, ADR 0029, ADR 0030, ADR 0031, ADR 0032, ADR 0033, ADR 0034

## Context

Policy v18 proved that the existing typed `CharacterExpressionPlan` v2 reaches the selected
foreground provider, but local production samples still sounded mechanical. The request repeated
nearly ready achievement and depletion interpretations across mode guidance and the late character
brief. The provider could copy that wording while ignoring the less literal dimensions that make
the reaction recognizably Satori's. The v18 renderer also omitted the selected register, care and
openness, and the depletion path could simultaneously expose `humor=0` and permit a
situation-directed barb.

This is an instruction-composition defect, not evidence that Satori needs another personality
description or a new persistent source. ADR 0034's relevance-scoped memory decision remains
correct: an ordinary turn must not invite a no-recall statement, while a request about the past
must retain grounded first-person uncertainty. Its memory decision is not superseded here.

The earlier blanket rejection of unsolicited advice is also too broad. Satori may notice a
specific useful next step when the current evidence makes it timely, such as an explicitly pending
commit. Conversely, a generic productivity suggestion inferred only from the word `project` is
not grounded character initiative and must not replace an emotional reaction.

## Decision

Behavior policy v19 becomes the next production-composition candidate. The last
provider-accepted policy remains unchanged until v19 passes its separately authorized sampled
gate.

`CharacterExpressionPlan` remains immutable, request-local and schema v2. Its persistent-state
owners, canonical personality source, closed expression vocabulary and absence of a write-back
path do not change. The ten-reason self-consistency validator, shared maximum-one retry and
canonical commit boundary also remain unchanged.

The provider request now has exactly one request-local character realization. Stable identity and
grounding invariants may remain in their trusted earlier positions, but turn-specific achievement
or depletion meaning is not restated there as nearly generated prose. The final developer message
is ordered as follows:

1. disclosure, grounding and mode invariants;
2. one compact character-realization block as the final trusted guidance before the user turn.

That final block renders all selected observable axes together: register, owned reaction, semantic
move, wit, care, openness, initiative and relational ease. It describes response behavior, not a
candidate sentence, stock phrase, enum label or fictional biography. Achievement and depletion
contracts constrain the required meaning and truth boundary without supplying a paraphrase for
the provider to copy.

The selector must keep its own typed directions coherent. A depletion turn whose cognition stance
is `LISTEN` and whose humor is zero does not receive a contradictory wit license. A fresh
relationship still forbids invented familiarity, but may receive a visible soft,
situation-directed edge when the turn is safe; closeness is not required for Satori to have a
character.

The existing initiative enum is reused. A pure deterministic step may issue a typed, request-local
practical-next-step license only from explicit current evidence or an explicit request. The
license permits at most one grounded, timely and proportionate next step. It does not authorize a
generic productivity lecture, a provider-inferred task, an external action or persistent
initiative state. In a vulnerable `LISTEN` turn, presence and the owned reaction take priority;
practical advice must not displace them.

The context manifest remains observational and non-authoritative. It exposes the complete selected
realization by adding the previously absent wit, care, openness and initiative axes as transient
`compare=False` fields. They cannot affect idempotent replay equality or become persistence input.
The practical license, where observable, is likewise request-local metadata rather than state.

A consistency retry reuses the same selected plan, relational ease and practical license. It may
correct only the detected typed violation; it cannot silently choose a different realization in
the same interaction.

Provider quality is evaluated as sampled evidence. The main OpenAI gate uses three independent
clean production sessions with the same two-turn achievement/depletion sequence. Every public
reply and metadata-only timing/usage result is preserved for a written human rubric covering
grounding, continuity, owned reaction, soft edge, care, advice discipline and natural complete
speech. Deterministic tests remain responsible for composition order, axis coherence, privacy,
retry stability and exact reply preservation. No LLM judge, output phrase rewriting or hidden
second personality source is allowed. Any paid run requires a separate explicit authorization
with call and cost bounds.

## Consequences

- One late coherent realization replaces competing and nearly scripted turn instructions.
- Satori can show a restrained edge in a fresh relationship without inventing closeness or
  attacking the user.
- Useful practical initiative becomes possible only when a typed request-local license has
  grounded it; generic advice remains a failure.
- The complete expression choice is inspectable without changing replay authority or persistent
  state.
- Offline correctness cannot establish character quality. Policy v19 remains a candidate until
  the three-session provider sample passes human review.
- ADR 0034's relevance-scoped memory behavior remains accepted.
- Stage 15, autonomous proactivity and all persistent personality, relationship, mood, emotion and
  memory contracts remain unchanged.
